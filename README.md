# ONE.RS - Optimal Network Excellence in Restaurant Supply - README

## Overview
ONE.RS is a platform that connects restaurant owners with suppliers, allowing easy access to ingredients and supplies for streamlined operations.

## Requirements
- **Node.js** 14.x or higher
- **npm** 6.x or higher

## Setup Instructions

1. **Install Dependencies**  
   Navigate to the project /frontend directory and run:

	npm install

2. **Run the Development Server**  
   Start the application in development mode with:

	npm run dev

3. **Run the Backend Server**  
   Not needed at the frontend is currently connected to AWS EC2 Backend


## Deployment
Alternatively, you can access the live application here:
	
	http://oners.s3-website-ap-southeast-1.amazonaws.com/#/
